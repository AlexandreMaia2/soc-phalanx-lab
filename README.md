# 🛡️ SOC PHALANX — Cybersecurity Home Lab

[🇧🇷 Versão em Português](README.pt-BR.md)

SOC PHALANX is my personal cybersecurity lab, created to study and practice Blue Team concepts in a controlled environment.

The project is being built step by step as I learn, test configurations, troubleshoot problems, and document the results.

## 🎯 What I'm studying

- Network segmentation and firewall rules with pfSense
- Windows Server and Active Directory
- Windows telemetry with Sysmon
- SIEM monitoring with Wazuh
- Network detection with Suricata
- DFIR and threat hunting with Velociraptor
- Security testing with Kali Linux

## 🧰 Lab Environment

- VMware Workstation
- pfSense
- Windows Server 2022
- Kali Linux

More tools will be added as the lab evolves.

## 📚 Documentation

Each stage of the lab is documented with:

- Configuration decisions
- Tests
- Troubleshooting
- Screenshots
- Results and lessons learned
