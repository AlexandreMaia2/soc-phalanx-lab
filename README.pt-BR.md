# 🛡️ SOC PHALANX — Laboratório de Cibersegurança

[🇺🇸 English Version](README.md)

SOC PHALANX é meu laboratório pessoal de cibersegurança, criado para estudar e praticar conceitos de Blue Team em um ambiente controlado.

O projeto está sendo construído passo a passo conforme estudo, testo configurações, resolvo problemas e documento os resultados.

## 🎯 O que estou estudando

- Segmentação de rede e regras de firewall com pfSense
- Windows Server e Active Directory
- Telemetria do Windows com Sysmon
- Monitoramento SIEM com Wazuh
- Detecção de rede com Suricata
- DFIR e Threat Hunting com Velociraptor
- Testes de segurança com Kali Linux

## 🧰 Ambiente do Laboratório

- VMware Workstation
- pfSense
- Windows Server 2022
- Kali Linux

Novas ferramentas serão adicionadas conforme o laboratório evoluir.

## 📚 Documentação

Cada etapa do laboratório será documentada com:

- Decisões de configuração
- Testes realizados
- Troubleshooting
- Screenshots
- Resultados e aprendizados
